# Satwik Parasar — Portfolio

A professional, dark-themed portfolio web app built with **Streamlit**, showcasing my projects, skills, and GitHub activity.

## Sections

- **Home** — hero, stats, about, tech stack, and filtered projects
- **Projects** — GitHub stats + filterable project cards (ML / Data Analytics / Web)
- **Contact** — socials and email

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy to Streamlit Community Cloud

1. Push this folder to a GitHub repo.
2. Go to [share.streamlit.io](https://share.streamlit.io) → **Create app**.
3. Pick the repo and set **Main file path** to `app.py`.
4. Click **Deploy**. Done.

All resources (avatar, GitHub stats) load from public URLs, so no secrets or files are required.# Portfolio
